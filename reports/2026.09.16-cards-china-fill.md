## One thing to note

`csv.DictWriter` writes CRLF by default, and both files were LF at HEAD. The
first write turned every line into a diff; both files were converted back to LF
afterwards, and the diffs are now only the rows actually changed (18 rows in
ccp-base-areas.csv). china.csv still diffs on every row against HEAD because
the earlier pass moved the paragraphs out of `en`; that is not this pass's
change. Worth knowing for any other agent using DictWriter on these files —
several sub-unit CSVs (taiwan, japan-islands, dei, indochina, burma-admin) are
CRLF at HEAD and several are not.
